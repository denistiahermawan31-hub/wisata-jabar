## Deskripsi Project

**WisataJabar** adalah aplikasi web eksplorasi wisata alam di Jawa Barat. Aplikasi ini dibangun dengan mengimplementasikan arsitektur **MVC (Model-View-Controller)** buatan sendiri menggunakan **PHP Native** untuk mengolah *backend* dan *routing*, serta **HTML5, CSS3, dan Native JavaScript** untuk antarmuka pengguna yang responsif, modern, dan interaktif.
